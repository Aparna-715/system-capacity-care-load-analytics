# System Capacity & Care Load Analytics

A data analytics dashboard for exploring trends in the Unaccompanied Children Program using Python, Pandas, Streamlit, and Plotly.

## Project Objectives

- Analyze trends in children entering and leaving different stages of care.
- Compare CBP custody counts with children in HHS care.
- Track changes in HHS care counts over time.
- Present key performance indicators (KPIs) through an interactive dashboard.

## Technology Stack

- Python
- Pandas
- Streamlit
- Plotly

## Project Status

Initial project setup. Dataset preparation, dashboard development, and analysis will be added in subsequent milestones.

## Important Note

The dashboard provides descriptive analysis of aggregate reported data. Its indicators should not be interpreted as official measures of system-wide backlog or individual case outcomes.
